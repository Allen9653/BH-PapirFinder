## BLOKER #2 (KRITIČNO — BIZNIS): PayPal plaćanje aktivira localStorage, ne Supabase

### Problem
U `Subscription.tsx`, `onApprove` callback poziva `upgradeToPaid()` iz `trial.ts`
koja upisuje status u `localStorage`. Ovo znači:
- Plaćanje se gubi pri clear cache-a
- Mobilna app ne vidi plaćanje
- Nema server-side verifikacije — korisnik može lažirati plaćanje
- `SubscriptionGuard` koristi `isSubscriptionActive()` iz `@/lib/subscription`
  koji vjerojatno čita localStorage — nije importovan iz `trial.ts`!

### Ispravak — Subscription.tsx onApprove callback:
```typescript
onApprove: async (_data, actions) => {
  try {
    const order = await actions.order.capture();

    // 1. Sačuvaj transakciju u Supabase
    const { data: { session } } = await supabase.auth.getSession();
    if (!session?.user) throw new Error('Korisnik nije prijavljen');

    const daysMap: Record<string, number> = {
      plan5days: 5, plan30days: 30, plan12months: 365
    };
    const days = daysMap[planId] || 5;
    const expiresAt = new Date(Date.now() + days * 86400000).toISOString();

    const { error } = await supabase.from('transactions').insert({
      user_id: session.user.id,
      plan_id: planId,
      paypal_order_id: order.id,
      amount_bam: parseFloat(amount),
      status: 'completed',
      expires_at: expiresAt,
    });

    if (error) throw error;

    // 2. Lokalni fallback (backward compat)
    upgradeToPaid(planId, expiresAt);

    setPaymentSuccess(true);
  } catch (err) {
    setPaymentError('Greška pri obradi plaćanja: ' + String(err));
  }
},
```

## BLOKER #4 (KRITIČNO — AUTH): Dual auth sistem — localStorage i Supabase Auth nisu sinhronizovani

### Problem
`trial.ts` registruje korisnike u `localStorage` (lokalni loginCode sistem).
`supabaseClient.ts` ima `signUpUser()` koji koristi Supabase Auth.
`auth.ts` koristi OBOJE — fallback na localStorage ako Supabase Auth ne radi.

Rezultat: korisnik se može "prijaviti" bez ikakvog Supabase sesiona, a pristup
se kontroliše localStorage bool-om koji se briše pri incognito/clear cache.

### Ispravak — Login.tsx i Register.tsx moraju koristiti ISKLJUČIVO Supabase Auth:
```typescript
// Register.tsx — zamijeni registerUser() sa:
const { data, error } = await signUpUser(email, password, name);
if (error) { setError(error.message); return; }
// Ne koristiti localStorage za registraciju

// Login.tsx — zamijeni loginUser() sa:
const { data, error } = await signInUser(email, password);
if (error) { setError(error.message); return; }
// Supabase automatski čuva sesiju
```

### access-control.ts — zamijeni localStorage check sa Supabase session:
```typescript
export async function getUserAccessLevel(): Promise<AccessLevel> {
  const { user } = await getCurrentUser();
  if (!user) return { canViewFormNames: true, canViewFormUrls: false, isAdmin: false, hasSubscription: false };

  const isAdminUser = isAdminEmail(user.email || '');
  if (isAdminUser) return { canViewFormNames: true, canViewFormUrls: true, isAdmin: true, hasSubscription: true };

  // Provjeri aktivnu pretplatu u Supabase
  const { data } = await supabase.from('transactions')
    .select('expires_at').eq('user_id', user.id).eq('status', 'completed')
    .gte('expires_at', new Date().toISOString()).limit(1).maybeSingle();

  return {
    canViewFormNames: true,
    canViewFormUrls: !!data,
    isAdmin: false,
    hasSubscription: !!data,
  };
}
```

## BLOKER #7 (VISOKI): Prijevod koristi MyMemory API (rate limited 500 req/dan besplatno)

### Problem
`translation.ts` koristi `https://api.mymemory.translated.net` — besplatni tier
dozvoljava 500 zahtjeva/dan po IP-u. Pri većem broju korisnika, svi prijevodi
prestaju raditi s greškom 429. Nema retry logike ni rate limit handlera.

### Ispravak — dodaj fallback i throttling:
```typescript
// translation.ts
const RATE_LIMIT_KEY = 'translation_rate_limit';

export async function translateText(text: string, targetLang: SupportedLanguage): Promise<string> {
  const cacheKey = `${text}_${targetLang}`;
  const cached = translationCache[cacheKey];
  if (cached && Date.now() - cached.timestamp < CACHE_DURATION) return cached.translation;

  // Provjeri rate limit
  const rateLimitData = JSON.parse(localStorage.getItem(RATE_LIMIT_KEY) || '{"count":0,"resetAt":0}');
  if (rateLimitData.count >= 450 && Date.now() < rateLimitData.resetAt) {
    console.warn('Translation rate limit reached, returning original');
    return text; // Vrati originalni tekst, ne baci grešku
  }

  try {
    const url = `https://api.mymemory.translated.net/get?q=${encodeURIComponent(text)}&langpair=bs|${targetLang}`;
    const response = await fetch(url);

    if (response.status === 429) {
      // Rate limited — postavi reset na midnight
      const tomorrow = new Date(); tomorrow.setHours(24,0,0,0);
      localStorage.setItem(RATE_LIMIT_KEY, JSON.stringify({ count: 500, resetAt: tomorrow.getTime() }));
      return text;
    }

    const data = await response.json();
    const translation = data.responseData?.translatedText || text;

    translationCache[cacheKey] = { translation, timestamp: Date.now() };
    // Inkrementiraj rate limit counter
    rateLimitData.count++;
    localStorage.setItem(RATE_LIMIT_KEY, JSON.stringify(rateLimitData));

    return translation;
  } catch {
    return text; // Uvijek vrati originalni tekst kao fallback
  }
}
```

## BLOKER #8 (VISOKI): SubscriptionGuard importuje iz nepostojećeg fajla

### Problem
`SubscriptionGuard.tsx` importuje `isSubscriptionActive` iz `@/lib/subscription`
ali taj fajl ne postoji u projektu! `lib/subscription.ts` nije u listi fajlova.

### Ispravak — kreiraj src/lib/subscription.ts:
```typescript
// src/lib/subscription.ts
import { getUserAccount } from './trial';

export function isSubscriptionActive(): boolean {
  const account = getUserAccount();
  if (!account) return false;

  if (account.status === 'paid' && account.paidExpiryDate) {
    return new Date() < new Date(account.paidExpiryDate);
  }

  if (account.status === 'trial' && account.trialExpiryDate) {
    return new Date() < new Date(account.trialExpiryDate);
  }

  return false;
}

export function getSubscriptionExpiry(): Date | null {
  const account = getUserAccount();
  if (!account) return null;
  const expiry = account.paidExpiryDate || account.trialExpiryDate;
  return expiry ? new Date(expiry) : null;
}
```
